Metaloscrap - Outil de scraping pour playlist musicale

# Description 

Metaloscrap est un outil dont le but est de se rendre sur le site Metalorgie (https://www.metalorgie.com/news), de faire défiler jusqu'à trouver le dernier post "LES SORTIES DE LA SEMAINE" et d'ajouter à une playlist Spotify les genres que l'utilisateur aura prédéfinis.
